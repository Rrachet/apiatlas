# APIAtlas

### Developer tool for discovering and validating public APIs

APIAtlas is a full-stack developer product focused on a practical engineering problem: finding APIs is easy; determining whether they are usable, reachable and trustworthy is harder.

## Engineering workflow

```text
API SOURCES
    ↓
STRUCTURED DATA
    ↓
SCHEMA VALIDATION
    ↓
DUPLICATE DETECTION
    ↓
HEALTH CHECKS
    ↓
RELIABILITY SIGNALS
    ↓
SEARCH / FILTER / INSPECT
```

## Technical focus

- Next.js + TypeScript
- Structured data modelling
- Schema validation
- Duplicate detection
- Automated health checks
- Search and filtering
- GitHub Actions
- Separation of source data, validation and presentation

## Why it matters

The project demonstrates backend-oriented reasoning around **data quality, validation, external dependencies and failure states**, rather than only building a UI.

## Current catalog

**102 API records · 32 categories**

The catalog tracks signals such as authentication, pricing, HTTPS, CORS, formats, OpenAPI, SDKs, region and verification.
